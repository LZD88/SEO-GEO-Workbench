# 曜见 YaoSight 生产化实施清单

## 1. 工程基线与部署入口

- [ ] 1.1 建立生产构建和明确的本机入口，固定 Node、NiubiGEO 与 Linux SiteOne 版本及校验信息。CI 在干净环境构建，成功输出版本和健康状态，并执行 `node --test 'test/*.test.mjs'`。
- [x] 1.2 添加 PostgreSQL 和私有产物存储的版本化迁移及最小权限配置。验证空库启动、重复部署和上一版本的兼容部署步骤。

## 2. 邀请、权限和历史导入

- [x] 2.1 实现邀请和 OIDC 登录、登出、持久会话及角色变更审计。集成测试覆盖邀请过期、重放、撤销成员、跨站写入和重启后会话。
- [x] 2.2 增加工作空间与站点项目界面，给列表、任务详情、基线、文章关联和报告下载加统一授权。通过两个测试空间逐项检查交叉访问被拒绝，查看者无法提交，HTML 产物按附件下载。
- [x] 2.3 增加旧历史的显式导入及操作说明。用旧记录夹具验证跨次导入去重、保留基线和报告关联，以及未知字段和历史中断正常展示。

## 3. 后台任务、配额与恢复

- [x] 3.1 建立作业、步骤、租约和提交去重。测试并发领取、重复请求、参数冲突和 Worker 租约到期后接管。
- [x] 3.2 接入用量预留、结算和暂停开关。并发测试确保预算不会超额。模拟数据缺失的上游结算，验证预留转待核对且日志不含密钥。
- [x] 3.3 将 GEO、SEO、文章导入和报告生成接入异步作业与界面状态。模拟 GEO 执行到一半时重启 Worker，验证同一作业可追踪、成功样本保留、外部调用未知时不自动重发。验证取消时停止派发后续请求，文章预览仍受项目权限约束。
- [ ] 3.4 为队列和供应商配置健康检查、延迟与失败指标、告警及值班说明。在预发布环境暂停一个异常渠道并核对仅影响其自身任务，检查日志脱敏。

## 4. 受限抓取与站点授权

- [ ] 4.1 让文章与图片请求、SiteOne 子进程统一使用受控抓取环境。使用隔离测试目标覆盖允许的公开页面、越界跳转、受限出网和超时，确认运行进程没有读取生产密钥的权限。
- [x] 4.2 增加 DNS TXT 验证、获授权主机和路径、明确的请求及页面上限。用受控站点验证未授权提交被拒，已授权站点可抓取，robots 跳过项可在覆盖状态看到。
- [x] 4.3 接入生产演示数据和图文预览的部分成功状态。验证图片缺失、正文截断、外部内容安全渲染以及本机示例仍可打开。

## 5. 持续 GEO 监测

- [x] 5.1 建立问题集及版本、日级周级计划和手动执行。验证同一计划时段不重复启动，暂停生效，编辑后旧运行参数可读。
- [x] 5.2 给有效响应、来源和联网证据写入渠道及模型快照，增加图片能力验证记录。测试无联网证据、中转路由变化及识图验证失败或过期时的选择和提交行为。
- [x] 5.3 实现有限竞品、原始证据回溯和提及与引用汇总。用固定回答验证两品牌同时提及、同名歧义、正文链接与正式引用、品牌别名和域名归属。
- [x] 5.4 实现按口径筛选的趋势和覆盖提示，展示实际样本数。用部分失败、低覆盖、配置变化和补跑沿用样本的固定数据核对分母、不可比较状态、时间和历史详情。

## 6. 可复查的技术 SEO

- [x] 6.1 用实际 SiteOne 固定报告构建版本化诊断解析器，保留原始报告。用测试站和夹具核对断链来源、重定向、索引指令、canonical、robots、sitemap、缺失标题和重复标题，无法判定的字段显式标记。
- [x] 6.2 做项目的 URL 问题列表、严重度筛选、原始报告下载和修复建议。用真实页面流程核对问题可以定位到对应 URL 和抓取记录。
- [x] 6.3 加入定期审计和两次结果比较。验证新增、持续、已修复与未验证，确认本轮漏抓、范围缩小或规则变化时不会误报修复。

- [ ] 7.1 在预发布按设计负载跑一轮邀请、授权站点审计、GEO 监测、文章优化、复测和恢复，记录队列目标、外部错误和高用量限制的实际结果。
- [ ] 7.2 从备份在隔离环境恢复 PostgreSQL 和私有产物，检查关联、权限、用量和暂停状态，记录达到的恢复时间和恢复点。
- [ ] 7.3 验证暂停对应渠道、关闭定期调度与回退到上一兼容版本的流程，保留执行证据并记录首批邀请空间正式开放的验收结果。
