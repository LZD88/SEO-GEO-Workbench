# GEO Retest

## Purpose

让用户在文章修改或品牌内容更新后沿用同一组问题与检测设置复测，并将新样本与可追溯的基线并排核对。

## ADDED Requirements

### Requirement: 复用检测配置并关联基线
从已结束的检测或关联报告复测时，系统 SHALL 复用保存的目标、问题、平台、模型及联网设置，并将新结果关联到选定的基线。

#### Scenario: 配置保持一致
- **WHEN** 用户对具备快照的记录发起复测且配置仍匹配
- **THEN** 系统沿用原配置发起新检测，在新结果显示基线与本次的成功样本数及各平台证据

#### Scenario: 模型或联网配置已变更
- **WHEN** 当前配置与基线快照不匹配
- **THEN** 系统提示无法按原条件复测，且不调用模型

#### Scenario: 旧检测没有配置快照
- **WHEN** 旧记录可映射到已知平台但没有快照
- **THEN** 页面提供明确标记的按当前配置复测入口，并在对照中标记旧条件未知
